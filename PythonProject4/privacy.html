Ваша конфіденційність — наш пріоритет

MYRMEDON INSPIRES поважає ваше право на приватність та захист персональних даних. Ми збираємо та обробляємо інформацію виключно для забезпечення якісного обслуговування.

1. Які дані ми збираємо

  • Ім'я та прізвище — для персоналізації звернення
  • Електронна пошта — для зв'язку та надсилання замовлень
  • Номер телефону — для підтвердження замовлень
  • Адреса доставки — для відправлення товарів
  • Історія замовлень — для покращення сервісу

2. Для чого ми використовуємо дані

  • Обробка замовлень — оформлення, доставка, оплата
  • Комунікація — підтвердження замовлень, інформування про статус
  • Покращення сервісу — аналіз відгуків та пропозицій
  • Маркетинг — тільки за вашої згоди

3. Захист даних

Ми впроваджуємо сучасні заходи безпеки для захисту ваших персональних даних:

  • Шифрування — всі дані передаються через захищені канали (SSL)
  • Обмежений доступ — тільки уповноважені співробітники мають доступ
  • Регулярний аудит — ми перевіряємо системи безпеки

4. Ваші права

  • Доступ — ви можете переглянути свої дані
  • Зміна — ви можете оновити або виправити дані
  • Видалення — ви можете запитати повне видалення даних
  • Відмова — ви можете відмовитися від маркетингових розсилок

5. Файли cookie

Ми використовуємо файли cookie для покращення роботи сайту:

  • Необхідні — для роботи кошика та оформлення замовлень
  • Аналітичні — для розуміння, як ви використовуєте сайт
  • Маркетингові — тільки за вашої згоди

6. Передача даних третім особам

Ми не передаємо ваші персональні дані третім особам, за винятком:

  • Служби доставки — для виконання замовлень
  • Платіжні системи — для обробки оплати
  • Випадки, передбачені законом — на вимогу державних органів
